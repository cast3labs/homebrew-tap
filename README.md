# cast3labs/homebrew-tap

Homebrew casks for [Omac](https://github.com/cast3labs/omac), a tiling window manager for macOS that
works with [Omarchy](https://omarchy.org)'s keybindings.

**Omac is in private beta.** There is no cask to install yet: it comes back with the first public
release. To follow along, watch [cast3labs/omac](https://github.com/cast3labs/omac)'s releases or visit
[omac.ghostype.ca](https://omac.ghostype.ca).

Omac is an independent, unofficial project, not affiliated with or endorsed by Omarchy, its creators
or 37signals LLC.
